# music-player

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A simple HTML/JS-based music player that uses the MediaSession API.

## Demo
https://code4fukui.github.io/music-player/

## reference
## Features
- Plays a predefined queue of songs
- Supports album art and metadata
- Provides media controls through the MediaSession API

## Requirements
No special requirements.

## Usage
1. Open the HTML file in a web browser.
2. The player will automatically load and play the first song in the queue.
3. Use the on-screen controls or the system media controls (e.g., on car stereos, lock screens, headphones) to control playback.

## Data / API
The player uses audio files and album art hosted on the [opendata-songs](https://github.com/code4fukui/opendata-songs/) repository.
