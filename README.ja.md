# music-player

メディアセッション API を使用したシンプルなミュージックプレーヤーです。

## 機能
- メディアセッション API に対応
- ジャケット画像の表示
- 前/次の曲の再生
- 再生/一時停止

## 必要環境
Web ブラウザ

## 使い方
ページにアクセスするだけで、曲が自動的に再生されます。ボタンで操作できます。

## データ・API
[opendata-songs](https://github.com/code4fukui/opendata-songs/) のオープンデータを使用しています。
